# ゆっくり音声ローカル連携

このフォルダは、GitHub Pages 上のランダム4桁数字サイトから、Chromebook 内で動かす AquesTalk10 のローカル音声サーバーへ接続するための準備用です。

## 注意

AquesTalk10 Linux は公式の評価版/製品版を利用してください。公式配布物やライセンスキーをこのGitHubリポジトリへアップロードしないでください。

AquesTalk10 Linux は公式マニュアル上、かな音声記号列からWAVを生成する共有ライブラリです。利用・配布にはライセンス条件があります。

1. AQUEST公式から AquesTalk10 Linux を入手
2. Linux環境にライブラリを配置
3. ライセンス条件を確認し、必要なライセンスを取得
4. このフォルダのローカルサーバー実装を使って `http://127.0.0.1:8765` で待ち受け
5. 公開サイト側では、このlocalhostだけを音声先として使用

評価版の継続利用や製品開発にはライセンスが必要です。
